# MEDALLIO AGENT PROTOCOL — Reusable template

The canonical template is generated by `tools/agent_handoff.py bootstrap`.

From a repository that already contains MAP:

```bash
python tools/agent_handoff.py bootstrap --target ../my-other-repo --project-name "my-other-repo"
```

The bootstrap operation is conservative:

- it creates missing MAP files;
- it copies the canonical protocol document;
- it copies the handoff CLI;
- it does not overwrite existing files;
- it does not run Git commit/push/merge;
- it does not call external model APIs.

After bootstrap, enter the target repository and run:

```bash
python tools/agent_handoff.py validate
python tools/agent_handoff.py status
```

Then replace the placeholder project/task state with verified repository facts.

## Minimal portable structure

```text
AGENTS.md
CLAUDE.md
docs/agentic/
  MEDALLIO_AGENT_PROTOCOL.md
  PROJECT_STATE.md
  ACTIVE_TASK.md
  DECISIONS.md
  HANDOFF.md
.agent/
  state.json
tools/
  agent_handoff.py
```

This is the minimum MAP contract. Projects may extend it without changing the core authority/handoff rules.
