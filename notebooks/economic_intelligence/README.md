# Economic Intelligence notebooks

Orden recomendado:

1. `00_contrato_y_auditoria.ipynb` — provenance, coverage y gates.
2. `01_puente_matrices_estadistica.ipynb` — identidad de stock y transformaciones.
3. `02_microeconomia_proyecto.ipynb` — oferta/demanda a nivel proyecto.
4. `03_macroeconomia_mercado.ipynb` — portafolio + macro externo opcional.
5. `04_clusters_gradientes_regimenes.ipynb` — factores latentes y sensibilidad de ML.
6. `05_forecast_demanda_y_agotamiento.ipynb` — demanda N meses + stockout.
7. `06_econometria_champion_challenger.ipynb` — inferencia condicionada + backtest.
8. `07_escenarios_oferta_demanda_pricing.ipynb` — what-if y pricing gates.
9. `08_comite_ceo_pmo.ipynb` — one-page executive operating review.
10. `09_experimentacion_mlops_decision_memory.ipynb` — drift, experimentos y outcomes.

Antes de abrirlos, ejecutar:

```powershell
scripts\70_instalar_economic_intelligence.bat
```

Para generar el Excel de absorción con universo completo actual + cobertura del ledger:

```powershell
scripts\63_exportar_absorcion_economica.bat
```
